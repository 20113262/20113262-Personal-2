    About the JSON Dataset & Year 2 Upgrade

    Originally built in Year 1 as a static multi-page site using Fomantic UI, this Year 2 overhaul replaces heavy external UI frameworks with pure CSS Flexbox and modular Vanilla ES6+ JavaScript.

    Each item in the Media & Tech Vault is structured as a JavaScript object containing primitive fields (id, title, creator, category, year, rating, featured) alongside a nested tags array for multi-criteria searching.
